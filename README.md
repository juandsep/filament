# Vibefilter for Filament

Filter your Filament tables by vibe.

Type a plain-English statement like "the customer is angry" and the table shows only the rows it is true for. Decisions come from [TypeSafe Jev](https://docs.typesafe.ai/api), with a calibrated probability per row.

> Work in progress. Not ready for use yet.

## Privacy

The text of the columns you choose is sent to an external API (TypeSafe) to be scored.
